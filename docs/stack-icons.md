# Stack icon sources

Brand icons are stored locally under `assets/stack/`, rather than fetched by visitors from a third-party CDN.

- Source: [Simple Icons](https://github.com/simple-icons/simple-icons).
- Pinned revision: `90646e4bf7f3b89df6c37e65baf3e7bc759a517c`.
- License: [CC0 1.0 Universal](licenses/simple-icons.txt). Product names and marks identify technologies; no endorsement is implied.
- React Native uses the React mark with its own visible label.
- Codex uses a project-authored terminal symbol; IndexedDB uses a project-authored database symbol. These are descriptive symbols rather than official product logos.

## Categories

Frontend follows the supplied technology list. Backend & Hosting groups runtime, framework, and hosting choices. SQLite is grouped with storage. Additional storage and workflow tools are supported by the existing projects: PostgreSQL in ClassPulse, Supabase/IndexedDB in StudyNest, MySQL/Docker in SeatFlow, and Vitest in StudyNest.
